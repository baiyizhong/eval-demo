# 场景评估器选择器设计

## 1. 目标与范围

改造“新增场景 / 编辑场景”抽屉中的“选择评估器”步骤，查询当前项目全部有效评估器，支持复选框多选和按评估器名称模糊搜索。

本次仅修改场景表单：

- 运行试验的评估器选择步骤不改造。
- 运行试验继续以场景已绑定的 `evaluatorIds` 为候选子集。
- 不修改后端、数据库、`langfuse/` 或 `dify/`。
- 继续使用前端 Mock 数据和现有 `/evaluators` 接口。

## 2. 有效评估器口径

评估器记录增加 `enabled: boolean`：

- `enabled === true` 且 `projectId` 等于当前项目时，允许在场景表单中选择。
- `enabled === false`、缺少有效状态或属于其他项目时，不展示在场景表单中。
- 编辑已有场景时，历史绑定但当前已停用或不属于当前项目的评估器不展示。
- 提交场景时，只保存当前有效评估器 ID，自动清理无效历史 ID。

现有 Mock 评估器补齐 `enabled`，并预置至少一条停用评估器用于验证过滤。

## 3. 查询与过滤

保留现有 `listProjectEvaluators`，供运行试验和其他既有页面继续使用。新增场景专用查询函数：

```ts
listActiveProjectEvaluators(api, projectId)
```

该函数复用现有全量分页拉取逻辑，再过滤当前项目中 `enabled === true` 的记录。

场景表单打开时加载一次有效评估器列表。搜索在前端本地执行，不增加 API 请求，也不改变 `/evaluators` 接口契约。

## 4. 选择器交互

新增模块私有 `ExperimentEvaluatorStep` 组件，职责为展示和筛选评估器，不直接请求 API。

组件内容：

- 标题“选择评估器”。
- 说明“作为场景默认评分配置，运行试验时仍可增删”。
- 搜索框，placeholder 为“搜索评估器名称”。
- 紧凑复选框列表，展示名称、类型、版本和输出变量。
- 选中状态由 `selectedEvaluatorIds` 和 `onSelectionChange` 受控传入。

搜索规则：

- 只匹配评估器名称。
- 自动去除关键词首尾空格。
- 使用不区分大小写的包含匹配。
- 搜索后不可见的已选评估器保持选中，不因过滤丢失。

空状态：

- 当前项目没有有效评估器：显示“当前项目暂无有效评估器”。
- 有有效评估器但搜索无结果：显示“未找到匹配的有效评估器”。
- 请求失败：显示加载失败提示，保留用户重试当前步骤的可能性。

## 5. 场景表单数据流

`SceneFormDrawer` 使用 `listActiveProjectEvaluators` 查询数据，并构造：

```ts
validEvaluatorIds = draft.evaluatorIds.filter((id) => activeEvaluatorIds.has(id))
```

页面展示、步骤校验和确认摘要使用净化后的有效选择。最终提交使用 `effectiveEvaluatorIds`：它先清理无效历史 ID，再在开启定时执行且没有选择时补入首个有效评估器。因此停用历史 ID 会被自动移除，定时执行的默认项也会被持久化。

用户勾选或取消勾选时，直接更新 `draft.evaluatorIds`。支持定时执行时至少保留一个默认评估器的既有校验保持不变。

## 6. 组件边界

### `project-evaluators`

- 保留全项目评估器分页加载。
- 提供当前项目过滤。
- 新增有效评估器过滤和查询函数。

### `ExperimentEvaluatorStep`

- 管理搜索关键词。
- 按名称过滤传入列表。
- 渲染复选框列表和空状态。
- 通过回调提交完整选择 ID 数组。

### `SceneFormDrawer`

- 执行有效评估器查询。
- 清理无效历史选择。
- 保留步骤校验、定时执行约束和提交逻辑。

## 7. 测试与验收

自动测试覆盖：

- 有效过滤同时校验项目和 `enabled === true`。
- 全量分页加载后再执行有效过滤。
- 名称模糊搜索忽略大小写和首尾空格。
- 搜索过滤不修改已选择 ID。
- 场景表单只使用有效评估器并在提交时清理无效历史 ID。
- 运行试验组件仍使用原 `listProjectEvaluators`，不切换为全项目有效评估器选择器。

视觉验收覆盖：

- 新增与编辑场景均显示搜索框和复选框列表。
- 输入名称片段后列表即时过滤。
- 多选状态在搜索切换后保持。
- 停用评估器不显示。
- 抽屉桌面和移动视口无横向溢出或内容重叠。
