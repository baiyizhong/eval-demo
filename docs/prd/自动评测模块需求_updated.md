# 自动评测模块需求

日期：2026-07-03

## 1. 背景与目标

自动评测模块用于在项目内创建、查看、管理和重新运行自动评测任务。本期只考虑 `pa-eval-frontend` 的前端交互 UI 实现，使用 mock 数据完成页面闭环，不接入真实后端接口，不设计数据库表结构，不修改 `pa-eval-backend/` 与 `langfuse/`。

本期目标：

- 在“应用评测”下提供自动评测任务管理页面。
- 展示自动评测任务列表、状态统计和运行结果摘要。
- 支持按任务名称搜索。
- 支持刷新列表、删除任务、重新运行任务。
- 点击任务列表项进入任务详情。
- 任务详情与评测报告合并为一个页面。
- 只有任务运行完成后，才允许查看评测报告内容。
- 新建自动评测任务采用三步流程：基础信息、选择评估器、选择评测数据与运行配置。
- 所有交互使用 mock 数据模拟成功、失败、运行中、空状态和异常状态。

## 2. 设计原则

- 前端闭环优先：页面、状态、交互和 mock 数据应完整表达自动评测核心流程。
- 不涉及后端实现：本期不新增真实 API、数据库迁移、Langfuse API 调用或调度逻辑。
- 贴合现有前端模式：优先复用项目已有页面容器、导航、表格、抽屉、弹窗、Toast、Confirm 和 shadcn/ui 组件。
- 列表工作台化：任务列表需要支持搜索、刷新、状态查看、操作反馈和空态处理。
- 详情报告一体化：任务详情页同时承载任务配置、运行记录、结果摘要和报告内容。
- 报告查看有门槛：任务未完成时不展示报告正文，只展示当前状态和不可查看原因。
- 操作可解释：删除、重新运行等高影响操作必须有确认、反馈和状态变化。

### 3.1 本期范围

| 功能域 | 功能点 | 说明 |
| --- | --- | --- |
| 模块入口 | 自动评测导航 | 在“应用评测”下新增“自动评测”入口 |
| 任务列表 | 列表展示 | 展示名称、状态、评估器、数据来源、样本量、成功/失败数、badcase 数、更新时间等 |
| 任务列表 | 状态统计 | 顶部展示全部、运行中、已完成、失败、未运行等统计 |
| 任务列表 | 名称搜索 | 按任务名称搜索，支持清空搜索 |
| 任务列表 | 刷新 | 手动刷新 mock 列表数据 |
| 任务列表 | 删除 | 二次确认后删除 mock 任务 |
| 任务列表 | 重新运行 | 支持对已有任务发起重新跑，mock 状态从运行中流转到完成或失败 |

| 任务详情/报告 | 报告查看 | 仅任务状态为已完成时展示报告内容 |

| Mock 数据 | 数据闭环 | 提供任务、评估器、数据集、trace 命中数、报告、运行记录等 mock 数据 |
| 状态体验 | 空/加载/错误 | 覆盖列表、详情、新建流程中的基础反馈状态 |

### 3.2 非本期范围

- 不接入真实 Langfuse Evaluators、Evaluation Rules、Job Executions、Scores 或 Datasets API。
- 不新增或修改后端接口。
- 不新增数据库表或 Alembic 迁移。
- 不修改 `langfuse/` 目录源码。
- 不实现真实任务调度、真实评分生成或真实 badcase 收集。
- 不实现评估器新建、编辑和调试。
- 不实现报告导出、报告版本对比、报告多人批注。
- 不实现真实权限控制，只保留前端权限位和按钮禁用占位。

## 4. 信息架构

“应用评测”模块内二级导航建议为：

- 数据集
- 人工评测
- 自动评测

自动评测包含两层页面：

1. 自动评测任务列表：管理任务、查看状态、搜索、刷新、删除、重新运行、新建任务。
2. 自动评测任务详情/报告：查看任务配置、运行记录、结果摘要和评测报告。

新建自动评测任务使用独立页面或右侧抽屉均可。本期推荐使用独立页面，原因是三步配置包含评估器选择、变量映射、数据来源和运行配置，内容较多，独立页面更利于后续扩展和返回确认。

## 5. 路由设计

建议在现有项目路由下新增：

```text
/projects/:projectId/evaluation/auto-evaluations
/projects/:projectId/evaluation/auto-evaluations/new
/projects/:projectId/evaluation/auto-evaluations/:taskId
```

路由行为：

- 进入 `/auto-evaluations` 展示任务列表。
- 点击“新建自动评测”进入 `/auto-evaluations/new`。
- 点击任务名称、列表行或“查看详情”进入 `/auto-evaluations/:taskId`。
- 详情页点击返回回到列表页。
- 从详情返回列表时，应尽量保留列表页的搜索词、分页和状态筛选。
- 进入详情页时，“自动评测”二级导航保持高亮。

## 6. 任务列表页

### 6.1 页面目标

任务列表页用于快速判断自动评测任务的运行状态，并提供常用管理操作。页面应适合高频查看，信息密度适中，避免营销化布局。

### 6.2 页面布局

页面结构：

- 顶部：应用评测二级导航。
- 标题区：标题“自动评测”，右侧主按钮“新建自动评测”。
- 状态统计区：展示任务总数和核心状态数量，点击统计项可筛选列表。
- 工具栏：名称搜索、状态筛选、刷新按钮。
- 主体：任务表格。
- 底部：分页。

### 6.3 状态统计

统计项：

| 统计项 | 说明 |
| --- | --- |
| 全部 | 当前项目下自动评测任务总数 |
| 运行中 | 状态为 `RUNNING` 的任务数 |
| 已完成 | 状态为 `COMPLETED` 的任务数 |
| 失败 | 状态为 `FAILED` 的任务数 |
| 未运行 | 状态为 `DRAFT` 或 `READY` 的任务数 |
| Badcase | 已完成任务中的 badcase 总数 |

交互规则：

- 点击统计项后，列表按对应状态过滤。
- 再次点击当前统计项可取消过滤，回到全部。
- 搜索词和状态过滤可组合生效。

### 6.4 搜索与刷新

名称搜索：

- 输入框 placeholder：`搜索任务名称`
- 搜索范围：任务名称。
- 支持中文、英文和数字。
- 支持清空。
- 搜索无结果时展示空态：“未找到匹配的自动评测任务”。

刷新：

- 点击刷新按钮后，表格进入短暂 loading 状态。
- mock 阶段刷新不需要请求真实接口，但可以重新计算运行中任务的展示进度。
- 刷新成功后提示：“自动评测任务已刷新”。
- 若 mock 模拟失败，提示：“刷新失败，请稍后重试”。

### 6.5 表格字段

默认列：

| 列 | 展示规则 |
| --- | --- |
| 任务名称 | 主文本，点击进入详情；副文本展示描述摘要 |
| 状态 | 使用 Badge 展示 `未运行`、`运行中`、`已完成`、`失败`、`已取消` |
| 评估器 | 展示评估器名称、类型和版本 |
| 数据来源 | 展示“数据集”或“Trace 过滤”，并展示样本量 |
| 采样率 | 百分比展示，如 `100%`、`30%` |
| 执行结果 | 展示成功、失败、待执行数量 |
| Badcase | 展示 badcase 数量；无则展示 `0` |
| 最近运行 | 展示最近运行时间；未运行展示 `-` |
| 创建人 | 展示创建人名称 |
| 操作 | 查看详情、重新跑、删除 |

状态文案：

| Mock 状态 | 页面文案 | 说明 |
| --- | --- | --- |
| `DRAFT` | 未运行 | 已创建但尚未运行 |
| `READY` | 待运行 | 已配置完成，等待运行 |
| `RUNNING` | 运行中 | 正在执行自动评测 |
| `COMPLETED` | 已完成 | 任务执行完成，可查看报告 |
| `FAILED` | 失败 | 最近一次运行失败 |
| `CANCELLED` | 已取消 | 运行被取消 |

### 6.6 行点击

- 点击任务名称进入详情页。
- 推荐整行可点击进入详情，但操作列按钮点击不触发行跳转。
- 键盘可访问性：任务名称应为可聚焦链接或按钮。

### 6.7 删除

删除入口：

- 每行操作列提供“删除”。

交互规则：

- 点击删除后弹出二次确认。
- 确认文案需说明：删除仅删除当前前端 mock 任务，不删除真实 trace、score 或 dataset 数据。
- 确认后从 mock 列表中移除任务。
- 删除成功后提示：“自动评测任务已删除”。
- 删除当前页最后一条数据后，分页应自动回退到仍有数据的页。

禁用规则：

- `RUNNING` 状态任务默认不允许删除。
- 运行中任务点击删除时提示：“任务运行中，暂不支持删除”。

### 6.8 重新运行

重新运行入口：

- 每行操作列提供“重新跑”。
- 详情页也提供“重新跑”按钮。

可操作状态：

| 状态 | 是否可重新跑 | 说明 |
| --- | --- | --- |
| `DRAFT` | 是 | 首次运行 |
| `READY` | 是 | 发起运行 |
| `COMPLETED` | 是 | 基于当前配置重新生成一次运行 |
| `FAILED` | 是 | 失败后重试 |
| `CANCELLED` | 是 | 取消后重跑 |
| `RUNNING` | 否 | 已在运行中 |

交互规则：

- 点击“重新跑”后弹出确认。
- 确认后任务状态变为 `RUNNING`。
- mock 阶段可通过定时器或刷新按钮模拟任务完成。
- 重新运行后应新增一条运行记录。
- 重新运行期间报告入口不可查看，直到任务再次变为 `COMPLETED`。
- 若从 `COMPLETED` 重新运行，旧报告可以在页面中保留为“上次报告摘要”，但主报告区展示运行中状态；本期也可简化为运行中时隐藏报告正文。

确认文案建议：

```text
确认重新运行该自动评测任务？
重新运行会基于当前 mock 配置生成新的运行记录，运行期间暂不可查看最新报告。
```

## 7. 新建自动评测任务

### 7.1 页面目标

通过三步流程创建一个 mock 自动评测任务，并在创建完成后回到列表或进入任务详情。

### 7.2 Step 结构

步骤：

1. 基础信息
2. 选择评估器
3. 选择评测数据与运行配置

顶部使用 Stepper 展示当前步骤。底部固定操作区：

- 第一步：取消、下一步
- 第二步：上一步、下一步
- 第三步：上一步、创建并运行、仅创建

规则：

- “取消”返回列表页；若表单已修改，需二次确认。
- 点击下一步时校验当前步骤。
- 创建成功后提示：“自动评测任务已创建”。
- “创建并运行”创建后任务状态为 `RUNNING`。
- “仅创建”创建后任务状态为 `READY`。

### 7.3 第一步：基础信息

字段：

| 字段 | 必填 | 控件 | 说明 |
| --- | --- | --- | --- |
| 任务名称 | 是 | Input | 用于列表和详情展示 |
| 任务描述 | 否 | Textarea | 说明评测目的 |
| Score Name | 是 | Input | mock 评分名称，如 `answer_quality` |

校验：

- 任务名称不能为空。
- Score Name 不能为空。
- Score Name 只允许英文、数字、下划线和短横线。
- 同一 mock 数据集中不允许完全同名任务，提示：“任务名称已存在”。

### 7.4 第二步：选择评估器

展示 mock 评估器列表，支持搜索。

评估器字段：

| 字段 | 说明 |
| --- | --- |
| 名称 | 评估器名称 |
| 类型 | `LLM-as-Judge` 或 `Code` |
| 版本 | 版本号 |
| 变量 | 需要映射的变量，如 `input`、`output`、`expected_output` |
| 更新时间 | mock 更新时间 |

交互规则：

- 单选一个评估器。
- 选中后展示评估器详情摘要。
- 若评估器包含变量，展示变量映射表单。
- 变量映射 mock 可提供固定选项：`trace.input`、`trace.output`、`dataset.input`、`dataset.expectedOutput`。
- 未选择评估器不能进入下一步。
- 必填变量未完成映射不能进入下一步。

### 7.5 第三步：选择评测数据与运行配置

第三步分为三块：

1. 数据来源
2. 运行配置
3. Badcase 配置

#### 7.5.1 数据来源

使用 Tabs 或 RadioGroup 在两种来源间切换：

- 已有数据集
- Trace 过滤

已有数据集：

- 展示 mock 数据集列表。
- 支持按数据集名称搜索。
- 展示数据集名称、描述、样本数量、更新时间。
- 单选一个数据集。
- 选中后展示“预计评测样本 N 条”。

Trace 过滤：

- 至少提供时间范围和环境。
- 可选提供 Trace Name、User ID、Session ID、Tags。
- 时间范围必填。
- 环境可多选。
- 提供“预估数量”按钮。
- 点击后展示“预计命中 N 条 trace”。
- 命中数量为 0 时禁止创建。

#### 7.5.2 运行配置

字段：

| 字段 | 必填 | 控件 | 说明 |
| --- | --- | --- | --- |
| 采样率 | 是 | Slider + Input | 范围 1%-100%，默认 100% |
| 运行方式 | 是 | RadioGroup | 创建并运行、仅创建 |

规则：

- 采样率不能小于 1%，不能大于 100%。
- 页面展示预计运行数量：`预计样本数 * 采样率`。
- 预计运行数量向上取整。

#### 7.5.3 Badcase 配置

字段：

| 字段 | 必填 | 控件 | 说明 |
| --- | --- | --- | --- |
| Badcase 收集 | 是 | Switch | 默认关闭 |
| 判断分数 | 开启后必填 | Select/Input | 默认使用 Score Name |
| 操作符 | 开启后必填 | Select | 小于、小于等于、大于、大于等于、等于 |
| 阈值 | 开启后必填 | Number Input | 数值型阈值 |

规则：

- 关闭时不展示阈值字段，或展示为禁用态。
- 开启后阈值必填。
- 阈值必须为数字。
- 示例文案：`score <= 0.6 将被标识为 Badcase`。

## 8. 任务详情/评测报告页

### 8.1 页面目标

详情页用于查看单个自动评测任务的配置、运行状态、执行记录和评测报告。报告不再使用独立页面，而是合并在详情页中。

### 8.2 页面布局

页面结构：

- 顶部返回区：返回列表按钮、任务名称、状态 Badge。
- 右侧操作区：刷新、重新跑、删除。
- 概览区：任务状态、样本量、成功数、失败数、badcase 数、最近运行时间。
- 配置区：基础信息、评估器、数据来源、采样率、badcase 规则。
- 运行记录区：展示最近几次 mock 运行记录。
- 报告区：根据任务状态展示报告内容或不可查看状态。

### 8.3 返回

- 点击返回按钮回到列表页。
- 返回后保留列表搜索词、分页和状态筛选。
- 若是从新建成功后进入详情，返回到列表首页即可。

### 8.4 操作

刷新：

- 刷新当前任务 mock 数据。
- 运行中任务可通过刷新模拟进度变化。

重新跑：

- 同列表重新运行规则。
- 重新运行后详情页状态立即变为 `RUNNING`。
- 报告区切换为“任务运行中，完成后可查看评测报告”。

删除：

- 使用二次确认。
- 删除成功后返回列表页。
- `RUNNING` 状态禁用删除。

### 8.5 报告查看规则

报告区展示规则：

| 任务状态 | 报告区展示 |
| --- | --- |
| `COMPLETED` | 展示完整评测报告 |
| `RUNNING` | 展示运行中状态，不展示报告正文 |
| `FAILED` | 展示失败说明和重新跑入口，不展示报告正文 |
| `DRAFT` | 展示未运行说明，不展示报告正文 |
| `READY` | 展示待运行说明，不展示报告正文 |
| `CANCELLED` | 展示已取消说明，不展示报告正文 |

运行中提示文案：

```text
任务正在运行，完成后可查看评测报告。
```

失败提示文案：

```text
最近一次运行失败，暂无法生成评测报告。可重新运行任务后再查看。
```

未运行提示文案：

```text
任务尚未运行，运行完成后将生成评测报告。
```

### 8.6 已完成报告内容

任务状态为 `COMPLETED` 时，报告区展示：

| 模块 | 内容 |
| --- | --- |
| 报告摘要 | 任务名称、生成时间、样本量、完成状态、核心结论 |
| 指标总览 | 平均分、通过率、失败率、badcase 率 |
| 分数分布 | 数值分段统计或简单柱状展示 |
| Badcase 分析 | badcase 数量、占比、主要原因、代表样本 |
| 样本列表 | 高分样本、低分样本、失败样本 |
| 运行质量 | 成功数、失败数、取消数、平均耗时 |
| 改进建议 | mock 生成的建议文本 |

本期报告展示以前端 mock 为主，不要求复杂图表。可优先使用轻量指标卡、表格和简易进度条。

## 9. Mock 数据要求

### 9.1 自动评测任务

```ts
type AutoEvaluationTaskStatus =
  | 'DRAFT'
  | 'READY'
  | 'RUNNING'
  | 'COMPLETED'
  | 'FAILED'
  | 'CANCELLED'

type AutoEvaluationTask = {
  id: string
  name: string
  description?: string
  scoreName: string
  status: AutoEvaluationTaskStatus
  evaluator: {
    id: string
```

## 10. 状态与异常体验

### 10.1 列表页状态

| 场景 | 展示 |
| --- | --- |
| 首次加载 | 表格 Skeleton 或 Loading |
| 无任务 | 空态文案“暂无自动评测任务”，提供“新建自动评测”按钮 |
| 搜索无结果 | 空态文案“未找到匹配的自动评测任务” |
| 刷新失败 | Toast 展示错误，保留当前数据 |
| 删除失败 | Toast 展示错误，保留当前数据 |

### 10.2 新建页状态

| 场景 | 展示 |
| --- | --- |
| 未选择评估器 | 下一步禁用或点击后展示校验 |
| 数据集为空 | 数据集 Tab 展示空态，可切换到 Trace 过滤 |
| Trace 命中为 0 | 禁止创建，提示调整过滤条件 |
| 表单未保存离开 | 二次确认 |
| 创建失败 | 停留当前步骤，展示错误提示 |

### 10.3 详情页状态

| 场景 | 展示 |
| --- | --- |
| 任务不存在 | 展示 Not Found 或业务空态，提供返回列表 |
| 运行中 | 概览展示进度，报告区不展示正文 |
| 已完成 | 展示完整报告 |
| 失败 | 展示失败原因和重新跑入口 |
| 删除成功 | 返回列表并提示成功 |

## 11. 前端验收标准

- “应用评测”下可以进入“自动评测”页面。
- 自动评测列表可以展示 mock 任务数据。
- 列表顶部可以展示状态统计。
- 点击状态统计可以筛选列表。
- 可以按任务名称搜索。
- 可以刷新列表并看到反馈。
- 可以删除非运行中任务，删除前有二次确认。
- 运行中任务不能删除。
- 列表和详情页都支持重新跑任务。
- 重新跑后任务进入运行中状态。
- 点击任务列表项可以进入详情页。
- 详情页和报告页合并在同一个页面。
- 只有 `COMPLETED` 状态任务展示评测报告正文。
- 非完成状态任务展示不可查看报告的原因。
- 详情页支持返回列表。
- 新建自动评测任务是三步流程。
- 新建任务支持“创建并运行”和“仅创建”。
- 新建成功后列表出现新任务。
- 所有数据来自前端 mock，不依赖真实后端。
- 不修改 `pa-eval-backend/`、`langfuse/` 或数据库结构。
