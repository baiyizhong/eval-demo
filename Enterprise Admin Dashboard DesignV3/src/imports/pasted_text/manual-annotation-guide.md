### 3.3 人工标注

#### 3.3.1 标注任务创建

入口：评测 → 人工标注 → 新建标注任务

点击「新建标注任务」按钮，弹出创建任务弹窗：

| 字段     | 类型          | 说明                                                 |
| -------- | ------------- | ---------------------------------------------------- |
| 任务名称 | 必填·文本框   | 标识该标注任务的名称，如"医疗QA质量标注 v1"          |
| 任务描述 | 选填·多行文本 | 描述标注任务的目标和背景信息                         |
| 评分维度 | 必填·多选列表 | 支持多选：执行速度、准确率、相关性、完整性、安全性等 |
| 处理人   | 必填·人员选择 | 指定负责该任务的标注者，支持单人或多人的角色分配     |

点击确认 → 任务创建成功 → 进入「待处理」状态。

#### 3.3.2 标注任务详情

**Step 1 — 进入任务详情：**

点击任务列表中的任意任务项，进入该标注任务的数据列表。

**数据列表字段：**

| 字段     | 说明                           |
| -------- | ------------------------------ |
| ID       | 数据唯一标识                   |
| 数据类型 | 如 Prompt / 对话 / 单轮问答 等 |
| 标记状态 | 待处理 / 已完成                |
| 标注人   | 当前负责该条数据的标注者名称   |

支持按标记状态、标注人等条件进行过滤筛选。

**Step 2 — 进入数据详情页：**

点击数据列表中的任意数据项，进入该条数据的详情页。

**详情页布局 — 左右分栏：**

```
┌────────────────────────────────────────────────────────────────────────────┐
│ [返回数据列表]  标注任务: 医疗QA质量标注 v1    数据项: #042    状态: 待处理  │
├────────────────────────────────┬───────────────────────────────────────────┤
│           消息详情              │              标注操作                      │
│  （左侧只读，不可编辑）          │                                          │
│                                 │  评分维度：                               │
│  消息ID: msg_00123              │  执行速度：[数字] 7/10                     │
│  时间: 2026-06-01 10:30:00      │  是否合规： [布尔] 是 ○ / 否 ●             │
│  SessionId: sess_abc456         │  质量等级： [分类] 优 ○ 良 ● 差 ○          │
│  UserId: user_789              │                                          │
│  环境: default                 │  标签：☐ Factual Error                    │
│                                 │      ☐ Hallucination                     │
│  【Input】                     │      ☐ Incomplete                        │
│  [{"role":"user",              │                                          │
│    "content":"问题..."}]       │  总体评价：[                        ]    │
│                                 │                                          │
│  【Output】                    │  备注（选填）：[                      ]    │
│  [{"role":"assistant",         │                                          │
│    "content":"回答..."}]        │                                          │
│                                 │                                          │
│  【Metadata】                  │                                          │
│  {"model":"gpt-4o",            │                                          │
│   "tokens":1024,               │                                          │
│   "latency_ms":1250}          │                                          │
├────────────────────────────────┴───────────────────────────────────────────┤
│              [添加至数据集]              [保存标注]      [上一条]  [下一条]  │
└────────────────────────────────────────────────────────────────────────────┘
```

**评分维度类型：**

| 类型                | 说明                     | 展示控件                              |
| ------------------- | ------------------------ | ------------------------------------- |
| 数字（Numeric）     | 整数或小数，支持范围约束 | 数字输入框或滑块（0-10 或自定义范围） |
| 布尔（Boolean）     | 是/否二值判断            | 单选按钮（是 / 否）                   |
| 分类（Categorical） | 从预定义选项中选择一项   | 下拉选择或单选按钮组（如 优/良/差）   |

**详情信息字段：**

| 字段      | 类型      | 说明                                        |
| --------- | --------- | ------------------------------------------- |
| 消息ID    | 字符串    | 数据的唯一标识                              |
| 时间      | 时间戳    | 消息生成时间，格式：YYYY-MM-DD HH:mm:ss     |
| SessionId | 字符串    | 所属会话 ID                                 |
| UserId    | 字符串    | 发送该消息的用户 ID                         |
| 环境      | 字符串    | 运行环境标识，默认为 "default"              |
| Input     | JSON 列表 | 消息输入内容，多轮对话为数组形式            |
| Output    | JSON 列表 | 模型输出内容，多轮为数组形式                |
| Metadata  | JSON 对象 | 附加元数据，如 model、tokens、latency_ms 等 |

**交互说明：**

- 左侧消息详情区展示上述所有详情字段，Input/Output/Metadata 以格式化 JSON 形式展示
- 右侧标注操作区根据评分维度的类型（数字/布尔/分类）动态渲染对应控件
- 支持键盘快捷键（←/→ 切换数据，1-9 快捷设置评分）
- 标注完成后数据状态自动更新为「已完成」

**Step 3 — 添加至数据集：**

点击「添加至数据集」按钮，弹出数据集选择弹窗：

| 字段       | 类型           | 说明                                                                   |
| ---------- | -------------- | ---------------------------------------------------------------------- |
| 目标数据集 | 下拉选择       | 从已有评测集中选择目标                                                 |
| 自定义修改 | 多行文本编辑器 | 支持在添加前对数据内容（input/expected_output/metadata）进行自定义编辑 |

确认后数据写入目标评测集，可在目标评测集的版本历史中查看更新记录。

#### 3.3.3 标注流程管理

**任务状态流转：**

```
待处理 → 进行中 → 待审核 → 已通过 / 已打回（重新标注）
```

| 状态   | 说明                                 |
| ------ | ------------------------------------ |
| 待处理 | 任务已创建，等待标注者开始处理       |
| 进行中 | 至少一名标注者已领取并开始标注       |
| 待审核 | 所有标注者完成标注，任务流转到审核者 |
| 已通过 | 审核者确认标注质量，数据进入评测集   |
| 已打回 | 审核者要求重新标注，任务退回给标注者 |

**一致性指标：**

- 当同一数据有多人标注时，展示各标注者之间的评分一致性（如 Cohen's Kappa 或 Krippendorff's Alpha）
- 一致性低于阈值（如 0.6）的数据自动标记为「需仲裁」，由高级审核员裁定最终值

**审核界面：**

- 查看所有标注者的独立评分，以及综合评分
- 对单条标注结果进行「通过 / 打回」操作，并填写打回理由
- 支持批量审核（勾选多条 → 批量通过 / 打回）
